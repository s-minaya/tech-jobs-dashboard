# Misión

## Qué construimos

Un dashboard de datos del mercado laboral tech europeo que visualiza ofertas de empleo,
skills demandadas, salarios y tendencias geográficas en tiempo real. Los datos vienen
de una base de datos PostgreSQL real y se presentan con un diseño profesional, limpio
y legible que fusiona el design system Halo con los efectos visuales característicos
del proyecto (aurora, GlowButton, DecryptedText).

1. **Dashboard** — visualizaciones dinámicas de datos del mercado tech (gráficas, mapas, heatmap, KPIs).
2. **Landing page** — presentación del proyecto con stats en tiempo real y acceso al dashboard.
3. **Sistema de filtros** — país, periodo, contrato, jornada, remote y categoría de skill.

## Para quién

- **Desarrolladores y profesionales tech** que quieren entender el mercado laboral europeo.
- **Recruiters y empresas** que buscan referencia de skills y salarios por país.
- **Sofi** — como proyecto de portfolio que demuestra competencia full stack y diseño de producto.

## Principios

- **Datos primero** — ningún dato es hardcodeado; todo viene de la API y la BD real.
- **Diseño coherente** — Halo como base estructural del dashboard, con los efectos visuales propios del proyecto integrados con criterio (aurora, GlowButton, DecryptedText, AuroraText desde la fase 3). La landing tiene su propia identidad y entra en el rediseño desde la feature 017, empezando por la versión móvil.
- **Dual theme** — dark mode y light mode coherentes con Halo; ambos modos son ciudadanos de primera clase.
- **Responsive real** — la experiencia móvil es tan cuidada como la de desktop.
- **Código limpio** — SDD, convenciones consistentes, sin malas prácticas acumuladas, tests y CI/CD.

## Qué NO es

- No es una bolsa de trabajo (no hay listado ni detalle de ofertas individuales).
- No es una app con autenticación ni perfil de usuario.
- No se añaden nuevas secciones de datos en este ciclo de rediseño.
